## 📘 Descripción del Proyecto

Este proyecto realiza un **análisis financiero comparativo** de tres
empresas colombianas del sector gastronómico:\
- **Crepes & Waffles**\
- **El Cielo**\
- **Frisby**

La información se obtiene de las bases de datos oficiales publicadas por
la **Superintendencia de Sociedades de Colombia**.

El análisis se centra en los años **2023 y 2024**, explorando tendencias
y comparaciones mediante visualizaciones construidas en **Power BI**.

------------------------------------------------------------------------

## 🎯 Objetivo del Proyecto

El propósito del proyecto es evaluar la situación financiera de estas
empresas utilizando tres indicadores clave:

-   **Total Activos**\
-   **Total Pasivos**\
-   **Patrimonio**

A través del análisis comparativo, se busca identificar comportamientos
financieros, fortalezas y posibles riesgos en cada empresa durante los
años evaluados.

## 📈 Visualizaciones Incluidas

En el archivo **Power BI (.pbix)** se incluyen:

-   Comparativo de Activos 2023 vs 2024\
-   Comparativo de Pasivos 2023 vs 2024\
-   Comparativo de Patrimonio 2023 vs 2024\
-   Tablas dinámicas y segmentadores por empresa\
-   Gráficos de barras, líneas y tarjetas KPI

------------------------------------------------------------------------

## 🧩 Relación entre los Datos

Todas las bases de datos se relacionan mediante:

-   **Razón social de la empresa**
-   **Año reportado**

Estos campos permiten integrar las tablas y facilitar la comparación
temporal entre empresas.

------------------------------------------------------------------------

## 📉 Resultados Generales (resumen breve)

-   Las tres empresas presentan comportamientos financieros distintos
    entre sí.\
-   Se observan variaciones relevantes en activos, pasivos y patrimonio
    entre 2023 y 2024.\
-   El análisis permite identificar tendencias clave y posibles
    decisiones de negocio.
